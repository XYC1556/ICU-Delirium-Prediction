# Python Analysis Scripts

This directory contains Python scripts for the ICU delirium
prediction and cross-hospital model transportability study.

## Main Components

- Data preprocessing and feature preparation
- Logistic regression modelling
- Cross-validation and bootstrap resampling
- Model discrimination and calibration assessment
- Cross-hospital model validation
- Sensitivity analyses

## Data Privacy

Only verified scripts suitable for public sharing
will be included in this repository.

Patient-level data from MIMIC-IV and eICU
will not be publicly distributed.
