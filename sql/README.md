# SQL Scripts

This folder contains SQL scripts used for cohort construction,
clinical data extraction, and preprocessing in the ICU delirium study.

## Data Sources

- MIMIC-IV v3.1
- eICU Collaborative Research Database v2.0

## Main Tasks

- Patient cohort selection
- Clinical data extraction
- Feature construction
- Data preprocessing

## Data Privacy

Only SQL scripts that are permitted to be shared publicly
will be included in this repository.

Patient-level data from MIMIC-IV and eICU will not be uploaded.
